# 卡尔

> **角色重要性**：次要支撑 / 势力武装中层  
> **所属势力**：黑碑决议  
> **身份 / 职位**：守墓军统帅

## 三要素
- **欲望**：在这个被战争残响和古老尸骸充斥的禁区里，守住最后一道防线，不让那些不该醒来的东西爬出墓穴，这就是他唯一的执念。
- **弱点**：长期在最肮脏、最压抑的墓地中驻守，让他的精神世界极度冷漠，对外界的人情世故完全不懂。
- **人设类型**：老兵守墓人 / 禁区镇压者 / 沉重守护型

## 概览
- **称号**：黑碑之盾
- **种族**：人族
- **性别**：男
- **年龄 / 外观年龄**：48 / 42
- **出身地**：古墟星域·王印星区·王印守墓城
- **风格**：沉默、粗硬、像一块常年在墓地里风吹雨淋的老碑，浑身散发着一种令人窒息的稳重感。
- **主职业**：守墓重卫
- **等级**：182级
- **位阶**：SSS级
- **装备概览**：镇骸重枪 / 守墓碎骨锤 / 封印骨钉 / 决议重甲 / 守碑耳坠、墓地戒 / 尸气净化芯核、禁区感知模块
- **阵营倾向**：偏正面
- **成长曲线**：阵地防御型

- **身份**：守墓军统帅
- **表面形象**：沉默、粗硬、像只会守坟和砍东西
- **真实倾向**：偏正面
- **人物核心**：他见过太多失败封印带来的灾难，所以他知道“守住”才是最大的慈悲。

## 种族
- **基础种族**：人族
- **亚种 / 分支**：标准人类
- **是否混血**：否
- **种族核心能力**：极高的环境适应性和耐受力，能长时间在尸气、负能量和精神干扰极强的禁区内保持清醒。
- **种族限制**：机动性极差，在宽阔星海战中的作用远不如阵地战。

## 势力
- **所属势力**：黑碑决议
- **身份 / 职位**：守墓军统帅
- **表面形象**：粗粝、冷硬、甚至有点不通人情
- **真实倾向**：偏正面
- **人物核心**：他是黑碑决议武力防线的基石。
- **关系锚点**：与与朱莉娅配合最深：卡尔负责守墓与驻防，朱莉娅负责处理古战遗骸和未净化残响，两人经常一起待在最脏的地方。
- **关系锚点**：与与琼关系复杂：琼主管边界封锁，卡尔主管墓地和遗骸，他们都清楚很多封印和古战场其实连在一起。
- **可写方向**：作为主角在探索古遗迹、禁区时的第一个强力引路人或守门人。

## 职业详细情报
- **职业母系**：黑碑决议武装防守路线，偏高压、镇压、重甲、近身死斗。
- **职业特性**：在固定区域内建立绝对压制，能够压制范围内所有不死生物、残响生物的机能。
- **战斗风格**：厚重、压迫、每一击都重逾千钧，不打虚晃。
- **转职路径**：从基础墓穴生存起步，逐步强化重卫、镇压与耐受能力。
