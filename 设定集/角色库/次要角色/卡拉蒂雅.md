# 卡拉蒂雅

> **角色重要性**：次要支撑 / 势力高层骨干  
> **所属势力**：黑碑决议  
> **身份 / 职位**：誓约主碑裁定长

## 三要素
- **欲望**：让那些古老的、神圣的誓约在千百年后依然能作为文明的最后一道枷锁，束缚住那些躁动不安的、企图挑战底线的野心。
- **弱点**：她太过于相信誓约的约束力，甚至到了一种近乎教条的程度，这让她在面对全新的、不可预测的变量时缺乏应变。
- **人设类型**：誓约裁定者 / 冷面守誓人 / 法统威严型
