# 厄普顿

> **角色重要性**：次要支撑 / 势力武装高层  
> **所属势力**：暴风王座  
> **身份 / 职位**：外海守望军总长

## 三要素
- **欲望**：在这个被狂风、雷暴和天灾撕裂的外海区域，守住暴风王座最后一道对外防线，不让任何外界势力染指王庭的威严，同时也想方设法让自己的士兵在风暴中少死一点。
- **弱点**：他太过于重视防守和边界，这让他对王庭那些激进扩张、主动求战的派系感到深深的担忧，也让他在某种程度上显得“保守”。
- **人设类型**：老牌将军 / 外海守望者 / 边界防守型

- **种族限制**：由于其力量来源于对“阵地”的防守，在开阔地带的遭遇战和机动战中，其战斗力会打折扣。

## 势力
- **所属势力**：暴风王座
- **身份 / 职位**：外海守望军总长
- **表面形象**：严厉、古板、甚至有点“死脑筋”
- **真实倾向**：偏正面
- **人物核心**：他是暴风王座外海防线的定海神针。
- **关系锚点**：与与佩妮关系最好：佩妮长期处理外海附庸和小港寨事务，比大多数王庭人物更懂民情与底层现实。
- **可写方向**：作为主角进入暴风王座领地时的第一个军事阻碍或可能的盟友。

## 职业详细情报
- **职业母系**：暴风王座武装防守路线，偏阵地战、大规模防御、环境利用、士兵加持。
- **职业特性**：在固定区域内建立“守望领域”，大幅提升范围内友军的防御力和抗灾性。
- **战斗风格**：稳扎稳打、通过坚固的防御和反击，逐步消耗并击溃对手。
- **转职路径**：从基础防御起步，逐步强化防卫、阵线与统筹能力。
