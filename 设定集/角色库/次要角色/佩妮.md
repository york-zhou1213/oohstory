# 佩妮

> **角色重要性**：次要支撑 / 势力中层  
> **所属势力**：暴风王座  
> **身份 / 职位**：外海会盟港主理人

## 三要素
- **欲望**：让暴风王座那份粗粝的征服欲下，还能留点真正能让普通人生存下去的港口、补给和贸易秩序。
- **弱点**：她太懂生活，这让她在王庭那些只懂征服的战争疯子眼里显得“不够狂烈”，也容易成为王庭政治斗争的软肋。
- **人设类型**：王座主理人 / 清醒现实派 / 附庸共主型

- **种族**：人族

- **主职业**：灾域物资官

- **装备概览**：会盟主理笔 / 压港短匕 / 灾象气压计 / 王庭执事裙甲 / 统筹耳坠、信物指环 / 补给调度芯核、港口全息投影仪
- **阵营倾向**：偏正面

- **真实倾向**：偏正面

- **亚种 / 分支**：标准人类

- **种族核心能力**：极强的现实协调能力，能够在复杂、混乱且充满敌意的多势力环境中生存并建立秩序。
- **种族限制**：在纯粹的破坏力上不占优势，更依赖于建立和维护稳定的体系。

## 势力
- **所属势力**：暴风王座
- **身份 / 职位**：外海会盟港主理人
- **表面形象**：务实、有耐心、甚至有点“好说话”
- **真实倾向**：偏正面
- **人物核心**：她是暴风王座在疯狂扩张后，唯一能维持其附属星域不崩溃的纽带。
- **关系锚点**：与很多附庸首领有直接关系：她是少数还会认真考虑“征服以后怎么活下去”的高层。
- **关系锚点**：与厄普顿关系最好：厄普顿是外海守望军总长，两人是暴风王座在边疆最稳固的防守派搭档。
- **可写方向**：适合作为主角在暴风王座领地内的第一个接触点，展示这个势力除了打杀之外的另一面。

## 职业详细情报
- **职业母系**：暴风王座行政与后勤路线，偏灾难环境生存、物资管理、据点维护。
- **职业特性**：能够感应区域内的资源分布，并在极端天象下建立微型稳定场，保障补给安全。
- **战斗风格**：防御、束缚、消耗战，通过改变局部环境资源流动来制约对手。
- **转职路径**：从基础生存起步，逐步强化物资管控、据点管理与多势力协作能力。
