# 克莱德

> **角色重要性**：次要支撑 / 势力顶级高层  
> **所属势力**：暴风王座  
> **身份 / 职位**：暴风王座现任统御者

## 三要素
- **欲望**：让暴风王座不仅仅是一个在灾域里苟延残喘的势力，而是要真正统御所有的灾海，将王权建立在最狂暴的雷霆之上。
- **弱点**：他太过于崇尚力量和统治，这让他对那些微妙的政治平衡缺乏耐心。
- **人设类型**：王权统御者 / 灾海霸主 / 强者为王型
