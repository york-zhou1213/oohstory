# 伊莲娜

> **角色重要性**：次要支撑 / 势力技术中层  
> **所属势力**：白潮  
> **身份 / 职位**：灵魂档案馆管理者

## 三要素
- **欲望**：将每一个进入白潮体系的灵魂样本、每一段珍贵的文明记忆都完整地封存在档案馆中，对抗那终将吞噬一切的遗忘。
- **弱点**：她接触了太多死者的记忆和消散的灵魂，这让她的现实感在逐渐剥离，有时会分不清自己是活在当下，还是活在过去的残响里。
- **人设类型**：记忆守门人 / 灵魂归档者 / 寂静记录型

## 概览
- **称号**：深潮录记官
- **种族**：人族
- **性别**：女
- **年龄 / 外观年龄**：38 / 31
- **出身地**：古墟星域·回响主星·记忆长廊
- **风格**：安静、极度严谨、周身带着一种常年浸泡在福尔马林般的冷寂感。她说话的声音很轻，仿佛怕惊醒了那些沉睡的意识。
- **主职业**：记忆编织师
- **等级**：135级
- **位阶**：S级
- **装备概览**：魂档导引笔 / 识海切片刃 / 灵识封存匣 / 潮汐档案袍 / 幻忆镜片、记录指环 / 意识锚定针、记忆扩容芯片
- **阵营倾向**：中立偏守序
- **成长曲线**：档案积累型

- **身份**：灵魂档案馆管理者
- **表面形象**：冷静、古板、像只关心编号和分类的管理员
- **真实倾向**：中立偏正面
- **人物核心**：她深信记忆是文明唯一的遗产，丢失了记忆的生命只是漂浮在星海里的空壳。

## 种族
- **基础种族**：人族
- **亚种 / 分支**：标准人类
- **是否混血**：否
- **种族核心能力**：极高的脑细胞稳定性，能够承载远超常人的外源记忆冲击而不发生人格崩溃。
- **种族限制**：身体机能由于长期缺乏运动和处于低耗能状态，其纯物理爆发力较弱。

## 势力
- **所属势力**：白潮
- **身份 / 职位**：灵魂档案馆管理者
- **表面形象**：安静、几乎不离开档案馆、对外界变化反应迟钝
- **真实倾向**：中立偏正面
- **人物核心**：她是白潮内部最稳固的“文明记录仪”，确保了白潮知识库的绝对纯净。
- **关系锚点**：与陆浮生、伊修斯长期配合：她掌握的资料是白潮很多重大决定的底层依据。
- **可写方向**：适合作为剧情中“翻阅禁忌历史”或“找寻主角前世/旧纪元线索”的关键点。

## 职业总览
- **种族职业**：人类适应体 7级
- **生存职业**：信息静修者 18级
- **主要职业**：记忆编织师 54级
- **专精职业**：灵魂归档长 36级
- **支援职业**：意识修复员 20级
- **总职业等级**：135级

## 职业详细情报
- **职业母系**：白潮灵魂研究路线，偏记忆存储、意识提取、灵魂样本修复。
- **职业特性**：能够通过接触或近距离共鸣，读取、复刻甚至暂时冻结目标的意识片段。
- **战斗风格**：幻术压制、记忆干扰、逻辑锁死，不打物理对抗。
- **转职路径**：从基础感知起步，逐步强化记忆承载、灵魂识别与高位意识归档能力。

## 【种族与职业融合进阶页】
