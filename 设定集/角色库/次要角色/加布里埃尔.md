# 加布里埃尔

> **角色重要性**：次要支撑 / 势力顶级高层  
> **所属势力**：星际联邦  
> **身份 / 职位**：联邦议长

## 三要素
- **欲望**：在这个群星失序、强权林立的纪元，强行维持住星际联邦这艘由于内部腐败、外部压力而摇摇欲坠的巨轮，不让它彻底解体。
- **弱点**：他太过于依赖政治平衡和程序正义，有时会为了大局而牺牲掉某些本该坚持的底线。
- **人设类型**：联邦政治家 / 议政掌控者 / 现实平衡型

- **基础种族**：人族
- **亚种 / 分支**：标准人类
- **是否混血**：否

## 势力
- **所属势力**：星际联邦
- **身份 / 职位**：联邦议长
- **表面形象**：联邦理想主义的最高化身
- **真实倾向**：中立
- **人物核心**：他其实是一个极端的现实主义者。
- **关系锚点**：与与奥菲莉雅长期搭档：加布里埃尔负责政治平衡与对外形象，奥菲莉雅负责法务与制度稳定，二人共同维持联邦运转。
- **关系锚点**：与与图尔曼关系复杂：图尔曼掌握防卫军和公共安全线，是联邦不可缺少的硬力量，但也最容易突破程序边界。
- **关系锚点**：与与维安莎长期互相利用：维安莎很会操盘议案与代表体系，加布里埃尔需要她，也知道她太会玩程序。
- **可写方向**：作为主角进入联邦高层圈时的主要引导者和潜在的政治对手。
