# 克蕾雅

> **角色重要性**：次次支撑 / 势力中层  
> **所属势力**：边荒同盟  
> **身份 / 职位**：拓殖与安置总会负责人

## 三要素
- **欲望**：在这个被战争、饥荒和混乱搅碎的边荒区域，为那些挣扎求存的人们建立起真正的安置点，让他们能有一块能种粮、能睡个安稳觉的土地。
- **弱点**：她太过于在意每一个具体的人，这让她在需要为了同盟整体利益而做出残酷抉择时感到极大的痛苦。
- **人设类型**：安置官 / 边疆生活线 / 安静坚毅型

- **职业母系**：边荒同盟民政与行政路线，偏组织、安置、协调、资源二次分配。
- **职业特性**：能够迅速理清区域内的资源脉络，并给出最高效率的人口分配方案。
- **战斗风格**：辅助性加持、控制敌方机动力、降低对手行动欲望。
- **转职路径**：从基础自救起步，逐步强化行政、安置与资源统筹能力。
