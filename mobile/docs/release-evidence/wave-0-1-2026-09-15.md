# OOHStory 波次 0/1 验证证据（2026-09-15）

## 已交付

- 产品 capability profile：本地格式/MDX 默认可用；OCR、云端和专用进度协议按独立
  编译期开关门控。
- “我的 → 内容工具 → 本地阅读”正式入口，不增加第五个主导航目的地。
- OOHStory progress v1 HTTP transport：Bearer、分页、条件写入/删除、409 当前记录、
  HTTPS 约束、超时和响应上限。
- 账号哈希分区的持久进度 outbox：离线保留、revision 基线、循环游标防护、并发冲突
  保留以及显式保留远端/重试本机的底层操作。
- Reader 阅读检查点继续先写本地与既有 `/api/v1/me/state`；专用 progress v1 在
  `OOHSTORY_PROGRESS_SYNC_ENABLED=true` 时增量记录和同步。
- ADR-001 记录双协议过渡、KOReader 隔离边界和回滚方式。

## 未形成的发布声明

- `OOHSTORY_PROGRESS_SYNC_ENABLED` 默认关闭；尚未授权或执行同源生产路由部署。
- OCR 默认关闭；当前可移植实现仅是高对比度英文 PNG 的测试/演示引擎。
- Kindle HUFF/CDIC、常见压缩 RAR、完整 MDX LZO/MDD 等仍在兼容性缺口中。
- 云存储、第三方生态、桌面签名安装包、TestFlight/App Store 和 Web 生产切换尚未发布。

## 环境缺口

KOReader 的真实 Nginx + TLS 夹具要求验收机安装 `nginx`。当前主机未安装该二进制，
因此该单项未运行；其余 KOReader 与跨平台同步协议测试通过。不得把这 43 项协议测试
替代真实 HTTPS 反代验收。

## 回滚

- 关闭专用 progress 编译期开关即可恢复为本地进度 + 既有账户状态同步。
- 隐藏本地阅读 capability 不删除用户文件。
- 服务端 KOReader 和 progress 服务可分别停用并保留数据；本轮未修改生产环境。
