# 日常消费记账系统

币种：**PHP（菲律宾比索）**

## 结构

- `expenses/2026-03.csv`：按月记录明细
- `reports/2026-03-summary.md`：按月汇总
- `reports/daily-template.md`：每日/每月统计规则说明

## 记账格式
每一笔消费记成一行：

```csv
date,category,amount_php,note
2026-03-15,餐饮,120.50,午饭
2026-03-15,交通,80,打车
```

## 统计口径
- **每日花了多少钱**：按 `date` 汇总当天 `amount_php`
- **每月花了多少钱**：按月份汇总所有 `amount_php`
- **花在了哪里**：按 `category` 汇总金额

## 你以后怎么用我
你只要告诉我一笔消费，例如：

- 今天午饭 120 PHP
- 打车 80 PHP
- 充值 500 PHP

我就会帮你追加到对应月份文件，并给你：
- 当天累计
- 本月累计
- 各分类累计
